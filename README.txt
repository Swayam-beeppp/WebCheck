# WebCheck

A simple website quality assurance tool: manual checklist, responsive
checklist, bug reporting with severity levels, and test reports. A small
Node.js scanner adds automatic link and page checks.

## Use it
1. Install Node.js 18 or newer.
2. Run: node webcheck-scanner.mjs
3. Open webcheck.html in your browser.
4. Enter a site URL, set the scanner address to http://localhost:3000,
   and click Scan site.

Or scan from the terminal: node webcheck-scanner.mjs https://your-site.com

Only scan sites you own or have permission to test.
